# kaisetsu-kit（日本語の概要）

台本を入れると、ナレーション付きのキャンバス解説動画が出てくる。小さな canvas エンジンと、一工程一本の Python ツール群を Agent Skill（`SKILL.md`）としてまとめたもの。詳しい書式は [README.md](README.md)。

- フレーム単位で決定的：ページは `async renderAt(t)` を公開し、各フレームは時刻 t だけで決まる。並列レンダリングも再現も可能。
- 解説部品：毛筆で一画ずつ書く漢字オープニング（KanjiVG の筆順データ）、全面シーンの寄り引きとページめくり、表・リスト・階段・ループ図・三つの門、
  顔と文字を避けて出る用語の「翻訳カード」と単語帳、原典が中国語のときの中・日・英三段組、字幕の上に収めるまとめ図。
- モーションコミック：コマごとにカメラが移動し、ページ転換、動画クリップを元のコマ位置に貼り戻す。
- 検査：全レイヤーの文字かぶり検査、納品チェック（完全デコード、−16 LUFS、トゥルーピーク、静止・黒画面検出、SRT、720p 確認版）、進捗は成果物から算出。

HyperFrames は不要。

## はじめかた

```bash
bash tests/smoke.sh      # 有料 API を一切使わずにパイプライン全体を通す
```

## 決まりごと

- 国名ではなく言語圏で呼ぶ（中国語圏・日本語圏・英語圏）。
- 原文が中国語の引用は中・日・英の三段組で見せる。
- 有料 API はまず試作（音声 10 行・動画 1 本）、リトライは上限つき、同じ素材が 3 回却下されたら止めて考え直す。
- 字幕枠とカードの下に文字を置かない。`qc_cards.py` の二つの検査が 0 になってからレンダリングする。
