# kaisetsu-kit（中文简介）

输入台本，输出带配音的画布解说视频。一个小型 canvas 引擎 + 一组单一职责的 Python 工具，打包成 Agent Skill（`SKILL.md`）。详细格式见 [README.md](README.md)。

- 逐帧确定：页面提供 `async renderAt(t)`，每一帧只由时间 t 决定，可多路并行渲染、可重放。
- 解说组件：毛笔逐笔写汉字开场（KanjiVG 笔顺数据）、全幅场景推拉与翻页、表格 / 列表 / 阶梯 / 因果循环 / 三道门；
  专有名词「转译卡」自动避开人脸与文字并收进单词帐；原典为中文时用中・日・英三栏；作业总结图整张放在字幕上方。
- 动态漫画路线：镜头逐格移动，换页演出，视频片段按原格裁剪框贴回页面。
- 检查：所有图层的文字遮挡检查、交付验收（完整解码、−16 LUFS、真峰值、静止与黑场检测、SRT、720p 审片版）、进度由产物计算。

不需要 HyperFrames。

## 快速开始

```bash
bash tests/smoke.sh      # 不调用任何付费 API，跑完整条管线
```

## 规矩

- 用语言圈称呼（华语文化圈 / 日语文化圈 / 英语文化圈），不用国家称呼。
- 引用的原文是中文时，一律中日英三栏。
- 付费 API 先小样（10 句配音 / 1 段视频），重试有上限，同一项被否 3 次就停下重想。
- 字幕框和卡片底下不许压字；`qc_cards.py` 两项都为 0 才渲染。
